# ✦ OBSIDIA — Handmade Gothic Fine Jewelry

> **“Cast in shadow. Worn like a vow.”**

An award-winning editorial fashion campaign and luxury gothic e-commerce experience. Forged with React, TypeScript, Tailwind CSS, GSAP ScrollTrigger, Lenis smooth scrolling, and cinematic WebGL/canvas alchemy.

---

## ✦ Key Features

- **Cinematic Hero Experience**: 
  - Dynamic hand video animation that reaches forward, flexes, and pauses at its resting pose.
  - Interactive 3D mouse parallax depth.
  - Ambient generative atmospheric soundscape synthesized via Web Audio API.
  - Responsive editorial clamp typography (*"Worn Like a Vow"* with burgundy accent).

- **Horizontal Pinned Vow Series**:
  - Vertical-to-horizontal translation scrubbed smoothly via GSAP ScrollTrigger.
  - Three signature pieces:
    - **01 — Crimson Vow**: Heart-cut Bohemian garnet in oxidized 925 silver filigree (`$690`).
    - **02 — Matte Eclipse**: Brushed architectural blackened bronze band (`$350`).
    - **03 — Onyx Halo**: Black pavé eternity band in blackened sterling silver (`$540`).
  - Interactive 3D card tilt with cursor-following specular spotlight reflections.

- **Atmospheric Smoke & Embers Alchemy**:
  - Slow-moving organic charcoal smoke with floating, glowing burgundy embers.
  - Real-time cursor repulsion physics swirling embers dynamically.
  - Centered statement: *“Forged in smoke — no two vows alike.”*

- **Craftsmanship & Specifications**:
  - 2x2 specification grid (`100% HANDMADE`, `14–92g PER PIECE`, `925 STERLING`, `∞ LIFETIME`).
  - Deep atelier manifesto detailing lost-wax centrifugal casting and liver-of-sulfur patinas.

- **E-Commerce & Client Care**:
  - Persistent shopping bag with slide-out drawer (`BagDrawer.tsx`) and full-page checkout (`/bag`).
  - Size selection with interactive ring measurement guide.
  - Correspondence newsletter with live validation.
  - Complete routes: `/collection`, `/craft`, `/product/:id`, `/journal`, `/bag`, `/privacy`, `/terms`.

- **Refined Creative Direction**:
  - Analog 35mm film grain overlay.
  - Desktop-only custom cursor with contextual badges (`INSPECT`, `ALCHEMY`).
  - Thin 1px bottom scroll progress bar.
  - Full support for `prefers-reduced-motion` and responsive devices (320px to 4K).

---

## ✦ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animation & Scroll**: GSAP 3 + ScrollTrigger + Lenis
- **Routing**: React Router (HashRouter for universal GitHub Pages & static hosting support)
- **Icons**: Lucide React
- **Audio**: Web Audio API (Generative atmospheric drone)

---

## ✦ Local Development

```bash
# Clone the repository
git clone https://github.com/akhileshtribhavannishad1-sketch/obsidia.git

# Navigate to project
cd obsidia

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
